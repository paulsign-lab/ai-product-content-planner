# AI 상품 콘텐츠 기획 - 경쟁 사이트 분석 스킬 패키지

경쟁 브랜드의 **자사몰 상품 페이지와 고객 리뷰**를 AI 에이전트가 직접 읽고, 소구점·불만·키워드를 근거와 함께 정리한 뒤
**상세페이지 초안, 숏폼 기획 3안, 주의 표현 점검, GEO용 Q&A**까지 만들어 주는 Claude Code 스킬 패키지입니다.

> AI가 리서치와 초안을 맡고, 사람이 판단과 최종 결정을 합니다.
> 모든 결과물에는 근거 URL과 증거 라벨(`[사실]` `[가설]` `[공백]` `[추정]`)이 붙고, 모르는 것은 지어내지 않고 비워 둡니다.

## 무엇을 만드나

```
경쟁 제품 URL 3~5개
   -> 01 사이트 스캔 (상품 정보, 메시지, 가격 표기)
   -> 02 리뷰 수집 (별점별 샘플, 짧은 인용, 수집 로그)
   -> 03 인사이트 (소구점 / 불만 / 고객 언어 / 갭 / 기회)
   -> 04 상세페이지 초안      -> 05 숏폼 기획 3안과 스크립트
   -> 06 주의 표현 점검       -> 07 GEO Q&A 초안 (선택)
   (03 뒤에서 사람이 포지셔닝을 선택)
```

## 빠른 시작
1. [`INSTALL.md`](INSTALL.md)를 따라 Claude Code(또는 데스크톱 앱)와 브라우저 도구를 준비합니다.
2. 작업 폴더에서 한마디: **`콘텐츠 분석 시작하자`**
3. 진행 방식을 고르고(**교육 모드** 권장 / 빠른 모드), 질문에 답하면 01~07 파일이 `outputs/<제품명>_<날짜>/`에 만들어집니다. 중간에 **포지셔닝은 사람이 직접 고릅니다.**
4. 단계별 활용 방법은 [`USAGE.md`](USAGE.md)에 있습니다.
5. 결과 예시는 [`examples/paulsign-us-serum/`](examples/paulsign-us-serum/)에 있습니다.

## 폴더 구성
```
ai-product-content-planner/
├─ USAGE.md                설치 후 단계별 활용 가이드
├─ INSTALL.md              설치 매뉴얼 (통합개발환경 / 데스크톱 앱 / 브라우저 도구 선택)
├─ .mcp.json.template      Playwright MCP 연결 템플릿 (.mcp.json 으로 이름 변경)
├─ templates/              brand.md, competitors.md 입력 양식
├─ examples/               결과 구조 예시 (가상 브랜드 PAULSIGN, 경쟁사는 익명 A~E)
└─ skills/                 스킬 8종 + 흐름 안내
   ├─ content-start/        입구. 교육/빠른 모드, 인테이크, 경쟁사 찾기 도우미, 01~07 진행
   ├─ site-scan/            경쟁 제품 페이지 기본 정보 (일반 웹 조회)
   ├─ review-harvest/       리뷰 수집 (브라우저, 별점별 샘플링, 예절 규칙)
   ├─ insight-synthesis/    소구점 / 불만 / 키워드 / 갭 분석
   ├─ pdp-draft/            상세페이지 초안
   ├─ shortform-draft/      숏폼 3안 기획과 스크립트 초안
   ├─ claims-check/         주의 표현 점검 (미국 x 화장품 상세, 그 외 일반 점검)
   └─ geo-qa-outline/       (선택) 블로그 아웃라인과 GEO Q&A
```

## 필요한 것
- Claude 유료 구독, Claude Code 또는 데스크톱 앱(Code 탭). Windows, Mac 모두 가능
- Node.js 18 이상(브라우저 도구인 Playwright MCP를 쓸 때만). 브라우저 도구 없이 리뷰를 직접 붙여 넣는 방식도 가능합니다
- 유료 분석 도구는 필요 없습니다. (Semrush, Apify는 쓰지 않습니다)

## 사용 원칙 (꼭 읽어 주세요)
- 로그인하지 않은 상태에서 **공개된 상품 페이지만** 읽습니다. 로그인, 결제, 계정이 필요한 화면은 건드리지 않습니다.
- 사이트마다 약관이 자동 수집을 제한할 수 있습니다. **소량(사이트당 상품 1개, 리뷰 수십 건), 사람 속도**로만 쓰고, 약관 확인과 사용 책임은 사용자에게 있습니다.
- 경쟁사 리뷰와 문구는 **분석 재료**입니다. 우리 콘텐츠에 복사하지 않고, 인용은 짧게(약 125자 이내) 출처와 함께 남깁니다.
- 리뷰어 이름, 사진 등 개인을 식별하는 정보는 수집하지 않습니다.
- **결과물(`outputs/`)은 내부 기획용입니다.** 경쟁사 이름과 리뷰 원문 인용이 들어 있으므로 외부에 게시하거나 공개 저장소에 올리지 않습니다.
- 규제 표현 점검은 참고용이며 법률 자문이 아닙니다.
