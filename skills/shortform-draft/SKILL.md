# shortform-draft - 숏폼 3안 기획과 스크립트 초안 (05번 파일)

> `{out}` = 이번 프로젝트의 결과 폴더 `outputs/<제품명>_<날짜>/` 입니다. 단독 실행할 때는 가장 최근 폴더를 쓰고, 둘 이상이라 모호하면 먼저 묻습니다. (`skills/README.md` 참고)

고객 불만과 고객 언어는 **훅**의 원재료입니다. 리뷰에서 나온 말로 시작하면 첫 3초가 "내 얘기"가 됩니다.

## 입력값
- `{out}/03_insights.md` (불만 클러스터, 고객 언어, 기대 불일치, 기회)
- `brand.md` (우리 제품 사실, 판매 언어, 제약)

## 실행 절차

### STEP 0 - 포지셔닝 확인
`{out}/03_insights.md` 맨 아래 "선택된 포지셔닝"을 읽는다. 비어 있으면 후보를 보여 주고 사용자가 고를 때까지 기다린다. 안의 훅과 구성이 이 문장과 어긋나지 않게 한다.

### STEP 1 - 3안의 역할 정하기
서로 다른 역할로 세 가지를 만든다.
- **A안 불만 훅:** 가장 빈도 높은 불만이나 두려움으로 시작 (예: "민감 피부는 새 제품이 무섭다")
- **B안 기대 설정:** 경쟁사 후기에서 나온 기대 불일치를 바로잡는 설명 (예: "수분 세럼과 장벽 세럼은 뭐가 다른가")
- **C안 사용 장면:** 루틴, 사용법, 질감, 패치 테스트 같은 **행동 가능한 정보**

### STEP 2 - 안마다 채울 항목
1. 타깃 불만 / 고객 언어 (근거: 03의 번호)
2. **훅 문구 2종** (0~3초, 영어 자막 + 한국어 해설)
3. **구성** (초 단위): 훅 0~3 / 전개 3~12 / 증거 12~20 / 행동 유도 20~25
4. **컷 리스트** (8~10컷): 장면, 샷 크기, 화면 텍스트, 필요한 소품
5. **영어 자막 스크립트 초안** (총 20~30초 분량)
6. **음성/BGM 방향**, 해시태그 5~8개 (설명 목적, 과장 금지)
7. **촬영 준비:** 소품, 장소, 연출자의 역할, 예상 촬영 시간

### STEP 3 - 주의 표시 (안마다)
- 효능 시연(전후 비교, 붉은기 감소 연출)은 **증빙이 있을 때만.** 없으면 "사용 장면과 질감" 중심으로 바꾼다.
- 인플루언서나 협찬이면 **광고임을 표시**해야 한다는 점(`#ad` 등)과 `claims-check`로 넘길 문구를 표시한다.
- 고객 리뷰를 영상에 쓰려면 **우리 제품의 우리 고객 리뷰**만 쓴다. 경쟁사 리뷰를 화면에 쓰지 않는다.

## 산출물
**`{out}/05_shortform.md`** - 3안 비교 요약표(역할, 훅, 길이, 난이도) + 안별 상세 + 촬영 체크리스트

## 핸드오프
- <- `insight-synthesis`
- -> `claims-check`: 자막과 훅 문구
- -> (선택) `geo-qa-outline`: 영상 설명란과 댓글 FAQ에 쓸 Q&A

## 작성 원칙
- 훅은 **고객이 쓴 말**에서 가져오되, 문장은 새로 쓴다. 경쟁사 브랜드명을 영상에 노출하지 않는다.
- 훅의 약속(첫 3초)을 영상 끝까지 지킨다. 낚시성 문구를 쓰지 않는다.
- 초안일 뿐이다. 최종 촬영과 문구는 사람이 확정하고 `claims-check`를 거친다.
