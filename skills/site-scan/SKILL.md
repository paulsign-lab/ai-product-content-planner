# site-scan - 경쟁 제품 페이지 기본 정보 (01번 파일)

> `{out}` = 이번 프로젝트의 결과 폴더 `outputs/<제품명>_<날짜>/` 입니다. 단독 실행할 때는 가장 최근 폴더를 쓰고, 둘 이상이라 모호하면 먼저 묻습니다. (`skills/README.md` 참고)

경쟁사가 **스스로 무엇이라고 말하는지**를 상품 페이지에서 읽어 옵니다. 숫자 데이터는 없지만 모든 항목에 출처 URL이 붙는 공개 증거입니다.

## 사전 준비
- 도구 연결은 필요 없습니다. **일반 웹 조회(WebFetch)** 를 씁니다. (리뷰는 다음 단계 `review-harvest`가 브라우저로 읽습니다)

## 입력값
- **`competitors.md`**: 경쟁 제품 상품 페이지 URL 3~5개 (브랜드사 지정이 최우선)
- **`brand.md`**: 우리 제품의 카테고리와 가격대 (비교 기준)

## 실행 절차

### STEP 1 - 상품 페이지 읽기
- 지정 URL이 있으면 그것을 그대로 읽는다. **스킬이 다른 제품으로 덮어쓰지 않는다.**
- 브랜드 홈페이지만 받은 경우: 홈페이지 메뉴, 컬렉션 링크(href)에서 **우리 제품과 같은 문제를 푸는 컬렉션**을 찾아 열고, 그 안의 베스트셀러나 첫 제품을 후보로 고른다.
  제형(세럼 등)보다 "같은 문제를 푸는가"가 우선이다. 맞는 컬렉션이 없으면 "해당 컬렉션 없음"이라 적고 "우리와 다른 문제를 푸는 제품"이라고 명시한다.
  출처를 `사용자 지정` 또는 `자동 선정(검증 필요)`으로 표기한다.
- **URL을 추측하지 않는다.** 404는 읽은 페이지의 링크에서 다시 찾는다.
- 질문(프롬프트)에는 **"원문 그대로 발췌, 요약 번역 금지, 없는 것은 '없음'"** 을 명시한다.

### STEP 2 - 사이트별 정리 (고정 항목)
1. **읽은 페이지**(URL, 접근 실패는 `ACCESS FAILED: URL, 이유`)와 제품 선정 출처(사용자 지정 / 자동 선정)
2. **제품명, 용량, 가격 표기.** 가격이 여러 개 보이면 옵션인지 할인인지 구분하고, 구분할 수 없으면 대표가를 정하지 말고 "복수 표기: $A, $B, 구분 미확인"으로 적는다
3. **핵심 메시지**(불릿)와 **대표 카피 원문 2~3개**(각각 출처 URL, 약 125자 이내)
4. **제품 주장 분류:** 성분 주장 / 효능 주장 / 수치·임상 주장(기관, 규모, 기간 표기 여부) / 사회적 증거(별점, 추천율).
   **사회적 증거와 임상 데이터는 구분한다.**
5. **페이지 구조 단서:** 섹션 순서(예: 히어로, 성분, 사용법, 리뷰, FAQ), 이미지 종류, 번들·구독 옵션
6. **타깃 단서:** 사이트가 겨냥하는 사람(피부 고민, 연령, 초보 여부). 미표기는 `미확인`
7. **리뷰 위젯과 리뷰 수:** 위젯 종류(Okendo, Yotpo, PowerReviews, Bazaarvoice, Judge.me 등 보이면), 표시된 총 리뷰 수. 일반 웹 조회로 안 보이면 "브라우저 필요"로 적는다.
8. **배송·반품 정책 한 줄** (보이면)

### STEP 3 - 접근 현황 요약표
사이트 x (페이지 성공 / 실패 / 일부) + 비고. 실패 이유(404, 지역 리다이렉트, 이미지뿐인 배너 등)를 적는다.

### STEP 4 - 표기 규칙 (파일 상단)
- `미확인` = 확인 못 한 항목 / `추정:` = 읽은 내용이 아니라 추론 / 라벨 없음 = 페이지에서 읽은 사실
- "WebFetch는 작은 모델이 읽어 답하므로 인용이 글자 단위로 정확하다는 보장이 없고, 긴 페이지는 뒤가 잘린다"
- "브랜드당 제품 1개만 읽었으므로 브랜드 전체를 대표하지 않는다"

## 산출물
**`{out}/01_site_scan.md`** - 접근 현황 요약표 + 사이트별 8항목 + 표기 규칙

## 핸드오프
- <- `content-start` 인테이크 (competitors.md, brand.md)
- -> **`review-harvest`**: 사이트별 읽을 URL, 리뷰 위젯 종류, 총 리뷰 수
- -> **`insight-synthesis`**: 경쟁사가 내세우는 소구점(주장)의 원재료
- -> **`claims-check`**: 경쟁사가 쓰는 수치, 효능 표현의 수위(참고)

## 작성 원칙
- 읽은 것만 적는다. 못 읽었으면 `미확인`. 가격을 추측하지 않는다.
- 경쟁사 사이트가 하는 말은 홍보 문구다. "이 제품은 ~하다"가 아니라 "이 브랜드는 ~라고 말한다"로 적는다.
