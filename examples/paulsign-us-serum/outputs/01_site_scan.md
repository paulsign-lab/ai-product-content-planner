# 01 경쟁 제품 페이지 스캔 (예시, 익명화)

> **표기:** `미확인` = 확인 못 함 / `추정:` = 읽은 내용이 아닌 추론 / 라벨 없음 = 페이지에서 읽은 사실.
> **한계:** 브랜드당 제품 1개만 읽었으므로 브랜드 전체를 대표하지 않는다. 가격은 옵션, 할인, 구독이 섞여 있어 대표가를 정하지 않았다(예시에서는 가격대만 적음).
> 이 예시는 실제 실행 결과를 익명화한 것이며, 카피는 원문 대신 요지로 적었다. 실제 실행 결과에는 URL과 원문 인용(약 125자 이내)이 들어간다.

## 접근 현황
| 경쟁사 | 상품 페이지 | 리뷰 위젯 | 표시된 리뷰 수 | 비고 |
|---|---|---|---|---|
| A | 성공 | Okendo 계열 | 100건대 | |
| B | 성공 | Yotpo 계열 | 수십 건 | 메타 설명이 키워드 나열 |
| C | 성공 | Okendo 계열 | 수천 건 | |
| D | 성공 | PowerReviews 계열 | 수백 건 | 리뷰에 같은 라인의 다른 제품 후기가 섞임 |
| E | 성공 | Bazaarvoice 계열 | 미확인 | 일부 리뷰가 페이지 구조화 데이터에 포함 |

## 경쟁사별 정리

### 경쟁사 A (케이뷰티, 장벽 세럼)
- **가격 표기:** 복수 표기(20달러대), 옵션/할인 구분 미확인
- **핵심 메시지:** 수분, 윤기, 수분 균형으로 유분 관리
- **제품 주장 분류:** 성분 주장 있음 / 효능: 수분, 윤기, 피지 / 수치, 임상 주장 미확인
- **타깃 단서:** 미확인

### 경쟁사 B (케이뷰티, 진정 앰플)
- **가격 표기:** 복수 표기, 대표가 미확정
- **핵심 메시지:** 메타 설명이 키워드 나열이라 **본문 메시지는 미확인** `[공백]`
- **타깃 단서:** 민감성, 여드름성 등 다수 피부 타입 키워드

### 경쟁사 C
- **가격 표기:** 단일 표기(50달러대)
- **핵심 메시지:** 손상된 장벽 회복, 톤 정리, 자극받은 피부를 "리셋"한다는 표현
- **제품 주장 분류:** 성분(오일류), 효능(장벽 회복, 진정) / 수치, 임상 미확인

### 경쟁사 D (한국 브랜드)
- **가격 표기:** 복수 표기(용량 또는 구성 차이로 추정), 구분 미확인
- **핵심 메시지:** 붉은기 진정, 장벽 케어
- **제품 주장 분류:** 효능 + **시간 주장("1시간 안에" 취지)** / 임상 수치 미확인
- **타깃 단서:** 민감성, 붉은기

### 경쟁사 E
- **가격 표기:** 복수 표기, 구분 미확인
- **핵심 메시지:** 장벽 케어, 붉은기, 보습
- **제품 주장 분류:** 효능 + **수치 주장(보습 80%대 증가 취지)** / 시험 기관, 대상, 기간 표기 미확인
- **타깃 단서:** 민감성

## 관찰 요약
- 5곳 모두 **"장벽(barrier)", "붉은기(redness)", "진정(soothing)"** 을 전면에 쓴다.
- 수치나 시간 주장을 쓰는 곳이 2곳(D, E). 근거 표기 방식은 미확인.
- `[공백]` B의 본문 메시지, 전 경쟁사의 임상 데이터 표기 여부.
