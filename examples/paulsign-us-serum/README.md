# 예시: PAULSIGN (가상 브랜드), 미국 페이스 세럼

이 폴더는 `콘텐츠 분석 시작하자`를 실행했을 때 나오는 결과의 **구조 예시**입니다.

- **PAULSIGN은 시연용 가상 브랜드**입니다. 제품 사실(성분, 향, 임상)은 모두 비어 있고, 그래서 결과물에도 `[공백]`이 남아 있습니다.
- **경쟁사는 "경쟁사 A~E"로 익명화했습니다.** 실제 강의 시연에서는 공개된 상품 페이지 5곳을 읽었지만, 브랜드명, URL, 리뷰 원문 인용, 정확한 가격과 리뷰 수는 이 저장소에 싣지 않았습니다. 불만과 칭찬은 요지와 대략의 건수만 남겼습니다.
- 읽은 리뷰는 사이트당 6~20건 수준이며 **통계가 아니라 관찰된 경향**입니다. 파일 안의 한계 설명을 함께 읽으세요.
- 실제 실행 결과는 `outputs/<제품명>_<날짜>/` 폴더에 저장됩니다. 이 예시는 구조를 보여 주려고 한 폴더에 모아 두었습니다.
- 여러분이 직접 돌리면 실제 브랜드와 URL이 들어간 결과가 나옵니다. 그 결과(`outputs/`)는 **내부 기획용**이며, 경쟁사 이름과 리뷰 원문을 그대로 외부에 게시하지 마세요.

| 파일 | 내용 |
|---|---|
| `brand.md`, `competitors.md` | 인테이크 입력 |
| `outputs/01_site_scan.md` | 경쟁 제품 페이지의 메시지, 가격 표기, 주장 |
| `outputs/02_reviews.md` | 리뷰 수집 로그와 별점별 요약 |
| `outputs/03_insights.md` | 소구점, 불만, 고객 언어, 갭, 기회 |
| `outputs/04_pdp_draft.md` | 상세페이지 초안 |
| `outputs/05_shortform.md` | 숏폼 3안 |
| `outputs/06_claims_check.md` | 주의 표현 점검 |
| `outputs/07_geo_qa.md` | GEO Q&A와 블로그 아웃라인 |
